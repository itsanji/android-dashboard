# Android Standby Mode

A React Native dashboard application for Android that displays customizable widgets on your home screen.

## Features

- **Dashboard Screen**: Display multiple widgets with customizable layouts
- **Widgets**:
  - 📅 Calendar: Shows upcoming events from your phone's calendar
  - 🌤️ Weather: Displays current weather based on your location
  - 🎵 Media Controller: Control currently playing media
  - ✏️ Custom Text: Add your own text notes
  - 🕐 Clock: Multiple clock styles (digital/analog)
- **Customizable Background**: Set images or videos as your dashboard background
- **Responsive Design**: Works across all screen sizes from small phones to foldable devices
- **Settings**: Easy widget management and customization

## Tech Stack

- **React Native** with TypeScript
- **Expo** for rapid development
- **React Navigation** for screen navigation
- **AsyncStorage** for data persistence
- **Expo Calendar, Media Library, Video** for native integrations
- **Local Expo module** (`modules/media-session`, Kotlin) for controlling other apps' media

## Getting Started

### Prerequisites

- Node.js 20 or newer
- Android Studio with the Android SDK, and JDK 17+ (`ANDROID_HOME` set)
- A physical Android device (USB debugging on) or an emulator

The app contains custom native code (the media controller), so it runs as a
**development build**, not in Expo Go.

### First run

```bash
cd android-standby-app
npm install
npm run android          # builds and installs the dev build, then starts Metro
# or, to choose a connected phone explicitly:
npm run android:device
```

The first build takes several minutes. After that:

- **JS/TS changes** reload instantly; just keep Metro running (`npm start` and
  open the installed app).
- **Native changes** (anything in `modules/*/android`, `app.json` plugins or
  native dependencies) need `npm run android` again.

`android/` is generated by `expo prebuild` and is not committed. If native
config gets out of sync, regenerate it with `npx expo prebuild -p android --clean`.

### Media controller setup

The media widget reads other apps' playback (Spotify, YouTube Music, ...)
through Android's media session API, which requires **notification access**:

1. Add the Media widget from Settings.
2. Tap **Allow access** on the widget and turn on _Android Standby Mode_.
3. Return to the app; the widget updates automatically.

If the toggle is greyed out ("Restricted setting", Android 13+ for apps not
installed from the Play Store): open _Settings → Apps → Android Standby Mode_,
tap **⋮ → Allow restricted settings**, then try again.

## Development Scripts

- `npm start` - Start Expo development server
- `npm run android` - Build and run the development build on a device/emulator
- `npm run android:device` - Same, choosing a connected device
- `npm run lint` - Run ESLint
- `npm run lint:fix` - Fix ESLint errors
- `npm run format` - Format code with Prettier
- `npm run type-check` - Run TypeScript type checking

## Responsive Design

The app supports multiple screen sizes:

- **XS** (< 360dp): Small phones, folded flip phones
- **SM** (360-599dp): Regular phones
- **MD** (600-839dp): Large phones, small tablets
- **LG** (840-1279dp): Tablets, unfolded foldables
- **XL** (≥ 1280dp): Large tablets

## Permissions

The app requires the following permissions:

- **Calendar**: To read and display calendar events
- **Media Library**: To access photos/videos for backgrounds
- **Location**: To show weather information
- **Notification access**: To show and control media playing in other apps (granted in system settings)

## Configuration

Edit `app.json` to configure:

- App name and package identifier
- Permissions
- Splash screen and icons
- Build settings
